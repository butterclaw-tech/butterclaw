# Security Policy

## Supported Versions
Security updates are strictly applied to the current production baseline. 

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | ✅ Active          |
| < 0.4.0 | ❌ Deprecated      |

## Our Philosophy: Evaluation before Execution
ButterClaw is built on the principle of asymmetric trust—the system is designed to autonomously tighten its posture while requiring human intervention to relax it. As a sentinel for agentic infrastructure, we treat vulnerabilities in our reasoning logic, credential vault, or execution layer as critical threats to system integrity.

## Reporting a Vulnerability
**Please do not open a public issue.** Public disclosure of a sentinel's vulnerability can compromise the agents it is sworn to protect. 

If you discover a vulnerability, please use GitHub's **Private Vulnerability Reporting** feature:

👉 [Report a private vulnerability](../../security/advisories/new)

### What to include:
- A clear description of the vulnerability.
- Proof of Concept (PoC) or reproduction steps.
- The potential impact on the Sentinel's paranoia levels or tool execution.

### Our Commitment
We will acknowledge your report within **48 hours** and provide a timeline for remediation. We follow a coordinated disclosure process to ensure the "Claws" remain sharp and secure for the entire community. 🦞
