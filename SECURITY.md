# Security Policy

## Supported Versions
Please ensure you are using the latest version of ButterClaw. Security updates are only applied to the current major/minor release.

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| < 0.4.0 | :x:                |

## Reporting a Vulnerability

We take the security of ButterClaw and the ButterVault incredibly seriously. 

If you discover a security vulnerability within this project, please **DO NOT** open a public issue. Instead, privately report it by emailing [security@butterclaw.tech].

**Please include:**
* A description of the vulnerability.
* Steps to reproduce the issue.
* Any potential impact on the execution layer or local key storage.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress in addressing it.
